GAMEDEV · QA / FASTFO — ECHO RANGE

GameDev и QA: как проверять игровую механику.

Практический QA-кейс на основе браузерной игры FASTFO — Echo Range. Мой основной опыт — Python, API, интеграции, автоматизированные проверки и AI-assisted разработка с 2022 года. Игровое тестирование — направление, в котором развиваюсь.

Открыть внешнее демо ↗PR #19 ↗
Границы проверки. Три наблюдения относятся к ограниченной проверке AI-ассистентом 28.11.2026, описанной в PR №19. Это не полный регрессионный прогон и не подтверждение авторства игры. Остальные сценарии — тест-дизайн, а не выполненные тесты. Доступность внешнего демо сейчас не подтверждена.
01 / SCOPE

Объект и условия тестирования.

Объект: движущаяся мишень, начисление очков, пауза, сложность, падение мишени и чёрные дыры, разрешения микрофона. Для повторного прогона фиксировать URL, дату, браузер и версию, ОС, устройство, параметры сложности, начальное состояние и скриншоты. Номер сборки и среда предыдущей проверки в PR не указаны.

Ожидаемые результаты непроверенных сценариев — рабочие гипотезы для согласования с требованиями игры. P1 — основной игровой сценарий, P2 — дополнительное покрытие. Три наблюдения не заменяют подтверждение всех ожидаемых результатов.

03 / BUG REPORT

Пример реального дефекта: доступность API.

QA-01 · Pulseboard /health/live. В GitHub Actions 27.11.2026 проверка главной страницы портфолио вернула HTTP 200, а проверка API Pulseboard — HTTP 503. Влияние: интерактивная доска может быть недоступна, хотя сайт открывается. Ожидание: доступный API возвращает HTTP 200. Воспроизведение: повторить GET /health/live и записать ответ. Приоритет: высокий для демонстрации. Текущий статус: нужна повторная проверка; причину сбоя не устанавливаем без диагностики.

04 / NEXT STEPS

Что проверять дальше.

Перед выпуском: проверить основной игровой сценарий, ошибки разрешений и перезапуск, повторить прогоны на двух устройствах, записать фактические результаты и дефекты с шагами воспроизведения. Пока это ограниченное наблюдение и план проверки, не заключение о готовности игры к релизу.
