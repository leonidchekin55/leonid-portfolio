ATLAS Studio — локальная платформа для проверки идей автоматизации бизнеса: заявки, запись клиентов, данные, контент, AI-помощник и управляемые рабочие процессы.

Проверить демосценарий ↗Все модули

Это безопасная публичная витрина на вымышленных данных — не работающая облачная CRM и не доступ к локальному backend. Настоящий MVP запускается локально; коммерческие интеграции, полноценная авторизация и разделение организаций ещё не реализованы.

Архитектура и ограничения

Одна локальная кодовая база, общий API и SQLite для прототипирования. Для коммерческого запуска нужны изоляция компаний, права доступа, безопасное хранение, мониторинг и реальные внешние интеграции.

Python + FastAPIHTTP endpoints, валидация сценариев, Swagger /docs.
SQLiteДемо-данные для CRM, записей, уведомлений.
Telegram (опционально)Простой бот через Bot API long polling при локальном запуске.
ТестыPytest для критичных API-сценариев, в том числе защиты от двойной записи.
